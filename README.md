# The Code Neuron - Setup & Deployment Guide

## Purpose

This document explains how The Code Neuron website is hosted, deployed, and connected to a custom domain.

It serves as a reusable reference for future products such as EstiMind.

---

# Architecture Overview

```text
GitHub Repository
        ↓
      Vercel
        ↓
thecodeneuron.dev
        ↓
      Users
```

## Why This Architecture?

### GitHub

**Purpose**

- Source code management
- Version control
- Collaboration
- Backup

**Why GitHub?**

- Industry standard
- Integrates directly with Vercel
- Every change is tracked
- Source code remains fully owned

### Vercel

**Purpose**

- Website hosting
- Deployment
- SSL management
- CDN delivery

**Why Vercel?**

- Free tier is sufficient for personal projects
- Automatic deployments
- Automatic HTTPS
- No server maintenance

### Namecheap

**Purpose**

- Domain ownership
- DNS management

**Important**

Namecheap owns the domain and manages DNS.

It does **not** host the website.

# Part 1 - Configure Domain in Vercel

## Step 1

Login to Vercel.

## Step 2

Open:

```text
Project
→ Settings
→ Domains
```

## Step 3

Click:

```text
Add Existing
```

## Step 4

Add:

```text
thecodeneuron.dev
```

## Step 5

Add:

```text
www.thecodeneuron.dev
```

## Step 6

Configure Root Domain

Domain:

```text
thecodeneuron.dev
```

Configuration:

```text
Redirect To Another Domain
```

Target:

```text
www.thecodeneuron.dev
```

Redirect Type:

```text
308 Permanent Redirect
```

Purpose:

Use one canonical URL.

## Step 7

Configure WWW Domain

Domain:

```text
www.thecodeneuron.dev
```

Configuration:

```text
Connect To Environment
```

Environment:

```text
Production
```

Purpose:

This becomes the actual website endpoint.

---

# Part 2 - Configure DNS in Namecheap

## Step 1

Login to Namecheap.

## Step 2

Navigate to:

```text
Domain List
→ thecodeneuron.dev
→ Manage
→ Advanced DNS
```

## Step 3

Remove previous hosting records if they point to an old hosting provider.

## Step 4

Add Root Domain Record

```text
Type: A Record

Host: @

Value: 76.76.21.21

TTL: Automatic
```

Purpose:

Connects:

```text
thecodeneuron.dev
```

to Vercel.

## Step 5

Add WWW Record

```text
Type: CNAME Record

Host: www

Value: cname.vercel-dns.com

TTL: Automatic
```

Purpose:

Connects:

```text
www.thecodeneuron.dev
```

to Vercel.

## Step 6

Save changes.

## Step 7

Wait for DNS propagation.

Typical time:

```text
5–30 minutes
```

---

# Part 3 - Verify Configuration

Return to:

```text
Vercel
→ Project
→ Settings
→ Domains
```

Expected:


SSL should be automatically generated by Vercel.
